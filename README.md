# Convex Hull Peeling for Outlier Detection

Computational Geometry Project — INFO-F420, Université Libre de Bruxelles.

## About the Project

This project explores **area-weighted convex hull peeling for outlier detection**, based on the research paper by Vinesh Sridhar and Rolf Svenning (2024).

The project includes a didactic webpage explaining the main geometric concepts, the greedy peeling strategy, and the algorithm's limitations.

An interactive JavaScript visualization allows users to generate point sets and observe how the convex hull changes when points are removed according to their impact on its area.

## Web Application

The application is implemented using HTML, CSS, and JavaScript.

To run it locally, download `index.html` and open it in a web browser. No installation or external libraries are required.

## Project Structure

- `index.html` — Didactic webpage and interactive visualization.
