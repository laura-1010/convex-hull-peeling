# AI Usage Journal

## Tools Used

ChatGPT (OpenAI) was used to support the understanding of the research paper, the development of the interactive webpage, and the organization of the theoretical explanations.

## Significant Interactions

AI assistance was mainly used to clarify concepts such as point sensitivity, convex layers, active points, tangent queries, and the greedy peeling algorithm. It also helped with the JavaScript implementation, code readability, webpage design, and the creation of geometric illustrations.

Some significant prompts focused on explaining Algorithm 1 step by step, understanding the role of active points, and improving code readability without changing its functionality.

## Verification and Corrections

AI-generated explanations and suggestions were reviewed and refined throughout the project. Some numerical examples were corrected, and the theoretical explanations were adjusted to distinguish the simpler greedy implementation from the optimized algorithm described in the paper. The webpage layout and code comments were also revised to improve clarity and readability.
